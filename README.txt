#  Sales Project

**AI Engineering Bootcamp — Module 02**

## Project Overview

This project focuses on data quality, basic sales insights, and CSV file operations using Python and Pandas.

The project is divided into two parts:

- **Part A:** Data Quality & Basic Insights
- **Part B:** CSV File Handling & Manipulation

## Project Files

- `Sunday_Sales_Project.ipynb` — Main notebook containing Part A and Part B.
- `sales_raw.csv` — Original input dataset.
- `cleaned_sales.csv` — Cleaned dataset generated in Part A.
- `sales_updated.csv` — Updated dataset generated in Part B.

## Requirements

- Python 3
- Pandas
- Matplotlib
- Jupyter Notebook or Google Colab

## How to Run

1. Download or clone this repository.
2. Make sure all project files are in the same folder.
3. Open `Sunday_Sales_Project.ipynb` in Google Colab or Jupyter Notebook.
4. Run the notebook cells sequentially from top to bottom.
5. The notebook reads `sales_raw.csv` and generates:
   - `cleaned_sales.csv`
   - `sales_updated.csv`

## Part A — Data Quality & Basic Insights

- Load and inspect the raw CSV dataset.
- Identify missing values and duplicate records.
- Clean and prepare the dataset.
- Calculate sales revenue.
- Group revenue by region and category.
- Create two labelled charts.
- Present two findings based on the data.
- Export the cleaned dataset.

## Part B — CSV File Handling & Manipulation

- Load the cleaned dataset.
- Add a 5% tax column.
- Increase Books prices by 10% using `.loc[]`.
- Remove a selected transaction.
- Create and remove a temporary column.
- Save and verify the updated CSV file.
